LIST OF CORE FUNCTIONALITIES - LANITE

1. Global Hotkey Activation: Uses 'Ctrl + Win' to trigger recording from any application.
2. Hold-to-Speak Logic: Starts recording on press and processes immediately upon release.
3. Direct Text Injection: Types transcribed text directly into the focused window/input field.
4. Offline Processing: Operates entirely locally using OpenAI's Whisper (via faster-whisper).
5. Voice Activity Detection (VAD): Uses Silero VAD to detect actual speech and ignore silence.
6. Multi-Model Support: Allows switching between Tiny, Small, and Medium models for speed/accuracy.
7. Real-Time Waveform Overlay: Provides visual feedback on audio levels while speaking.
8. Background Operation: Runs as a lightweight system tray application.
9. IPC Singleton: Prevents multiple app instances and handles "wake-up" requests.
10. Dictation History: Maintains a local database of past transcriptions with timestamps.
11. Usage Analytics: Tracks total words, session counts, and average transcription speeds.
12. App-Target Tracking: Records which specific applications were used for dictations.
13. Filler Word Removal: Option to automatically strip verbal fillers like "um" and "uh".
14. Trailing Space Management: Automatically appends a space after transcription for seamless typing.
15. Comprehensive Settings UI: Premium dark-mode dashboard for configuration and management.
16. Auto-Start: Optional registry-based "Start with Windows" functionality.
17. Smart Device Selection: Auto-scans and selects the best available microphone.

--------------------------------------------------------------------------------
HOTKEY VISUAL OVERLAY (HUD) BEHAVIOR
--------------------------------------------------------------------------------

When the user triggers the 'Ctrl + Win' hotkey, a floating Head-Up Display (HUD) appears at the bottom of the screen to provide immediate visual feedback.

🎙️ VISUAL APPEARANCE
- Form Factor: A slim, rounded "pill-shaped" horizontal bar (Width: 520px, Height: 72px).
- Styling: Dark translucent background (#141414) with a subtle border (#2a2a2a).
- Elements:
    • [Left] White 🎙 emoji icon.
    • [Center] 12-bar dynamic waveform visualizer.
    • [Right] Status text (Segoe UI, 9pt).

✨ ANIMATION STATES

1. STATE: LISTENING (Hotkey Held)
   - Waveform Activity: Bars react in real-time to the user's audio amplitude (volume).
   - Color Transition: Bars lerp (linearly interpolate) from Deep Blue (#1a4fd6) to light Sky Blue (#5eb8ff) as volume increases.
   - Text Hook: Displays "Listening..." to confirm active capture.

2. STATE: PROCESSING (Hotkey Released)
   - Waveform Activity: Transitions to a "calm ripple" animation (sinusoidal wave).
   - Color Shift: Changes to a muted Slate Grey (#4a4a5a) to signal the AI is thinking.
   - Text Hook: Displays "Processing..." while Whisper generates the text.

🛡️ TECHNICAL UX PROPERTIES
- Click-Through: The overlay uses Win32 layered window flags (WS_EX_TRANSPARENT), meaning it is invisible to mouse clicks. Users can click "through" it to hit buttons in the app behind it.
- Focus Isolation: Never steals focus from the text cursor (WS_EX_NOACTIVATE).
- Topmost: Guaranteed to stay visible over full-screen apps and browsers.
